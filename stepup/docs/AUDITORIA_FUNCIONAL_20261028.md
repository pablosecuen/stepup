# Comparación funcional app ↔ web — 28/10/2026

La estructura de pantallas, acciones y datos es el criterio. No se comparan node_modules, builds, configuración del editor ni número de líneas. Se tomó el catálogo funcional existente y se corrigió contra las rutas, componentes, acciones y consumidores del código publicado d8c25a0. Las dos sesiones web ya están publicadas desde 7dde04b. La app original permanece intacta.

## Qué significa el porcentaje

Catálogo: 89 bloques. Se excluyen 2 (datos propios de QA web y estética). Base comparable: **87 bloques**. Todos pesan igual; bloques amplios pueden contener varias acciones. ALU-16/PAG-05 y REG-11/INI-07 se solapan: este índice es una lectura del catálogo, no un cálculo de esfuerzo restante. No es una auditoría de corrección de cada rama ni una garantía de ausencia de errores.

- 71/87 disponibles o con diferencia vigente: **81.6 %** (65 disponibles + 6 diferencias vigentes).
- 12/87 parciales: **13.8 %**.
- 4/87 faltantes: **4.6 %**.
- Si se asigna medio punto a cada parcial: **índice estructural aproximado 88.5 %**. Es una ponderación declarada, no «88.5 % probado» ni equivalencia exacta.

No se calcula porcentaje de funcionamiento confirmado: no existe una prueba comparable y actual de todos los circuitos y dispositivos. Una suite que incluye pruebas del núcleo original copiado no acredita la interfaz publicada.

## Dos dispositivos (pedido nuevo)

Dos navegadores/PWA simultáneos, con cookie propia y registro separado del permiso de respaldo de la app nativa. El primero y segundo no se expulsan; el tercero elige qué sesión reemplazar. Cerrar sesión es local. Una sesión reemplazada se rechaza en el servidor y no reaparece por el chequeo periódico. Pruebas PostgreSQL aisladas: 23 comprobaciones, incluidas tres altas concurrentes, dos lugares como máximo, aislamiento entre cuentas, repetición, versiones obsoletas, renovación, vencimiento y cierre local. Falta acreditar dos dispositivos físicos y edición concurrente del mismo formulario; permitir sesiones no equivale a coeditar un borrador.
